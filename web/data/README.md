# Data in this folder

Every file here was computed from public data by the Python scripts in `pipeline/`:
NISAR L2 GCOV radar products (NASA-ISRO, NASA ASF DAAC), VIIRS images and heat detections (NASA GIBS / FIRMS),
official fire perimeters (NIFC), hurricane best tracks (NOAA NHC), wind (Open-Meteo / ERA5) and orbital elements (CelesTrak).

**Use of AI (SI).** The scripts that produced these files were written with the help of an AI assistant
(Claude by Anthropic), so the files are SI-assisted, computed data. No values were invented by an AI:
each number comes from the source data through the method described in the project README.
